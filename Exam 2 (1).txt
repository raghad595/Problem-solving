- Private : Restricts access to within the class, ensuring data encapsulation and security. Access in class only
- Protected : Similar to private, but accessible by derived classes, facilitating inheritance and polymorphism. Access in base & derrived class only

/*1- Overloading: Overloading refers to the ability to define multiple functions in the same scope with the same name but with different number of parameters or different types of parameters.
- Compile-Time: Overloading is resolved at compile time, based on the number and types of arguments passed to the function.
(Overriding must have the same method signature (same method name, parameters, and return type)
- Example:*/
/*int add(int a, int b);
double add(double a, double b);
*/

It usually involves inheritance, where a subclass redefines a method declared in its superclass.
- Run-Time: Overriding is resolved at runtime based on the actual object type.
- Example: */
